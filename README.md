# Store Collective

Store Collective is a full-stack e-commerce clothing website developed using Python, Flask, SQLite, HTML, CSS, and JavaScript. The website allows customers to browse products, view detailed product pages, add items to a shopping basket, and complete purchases through an integrated checkout system.

The project was built to demonstrate modern web development principles including database integration, server-side rendering, responsive design, and payment processing.
The product images used throughout this project are placeholder examples and have been included for demonstration purposes only.

Store Collective was developed as a proof-of-concept e-commerce application focused on functionality, database integration, product management, and user experience. Product images are used to simulate a realistic online store environment and do not represent official products, inventory, or branding.

## Features

### Product Management
- Browse products by category
- Product detail pages
- Product search functionality
- Dynamic product loading from a database

### Shopping Experience
- Shopping basket system
- Checkout process
- Payment form integration
- Order success and cancellation pages

### Website Content
- Homepage slideshow
- About page
- Responsive navigation
- Custom styling and branding

### Backend Functionality
- Flask routing
- SQLite database integration
- Session management
- Dynamic template rendering using Jinja
